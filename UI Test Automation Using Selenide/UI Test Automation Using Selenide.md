## **Project: UI Test Automation Using Selenide**

### **Project Overview**

This project is designed to help QA engineers gain practical experience in automating UI testing using **Selenide**, a powerful framework built on top of Selenium. Participants will build and maintain automated UI test suites that validate the core functionalities of a sample web application. The project emphasizes simplicity, stability, and maintainability of tests using Selenide's fluent API and concise syntax.

### **Objectives**

- Automate common UI scenarios such as login, form submission, and navigation.

- Apply the Page Object Model (POM) for test structure and maintainability.

- Integrate assertions, waits, and test reporting using Selenide's built-in features.

- Optionally run tests in headless mode and across multiple browsers.

### **Task**

Application under test:

- [Swag Labs](https://www.saucedemo.com/) (User login, product search, product details page, cart functionality, and checkout)

- Setup the automation project

- Create Page Object classes for key pages

- Selenide based test cases

- Implement soft/hard assertions and automatic waits using Selenide.

- Configure test execution on headless browsers like Chrome or Firefox.

**Implement test scenarios for:**

1. Smoke test suite (Login, product page)

2. Regression test suite (Cart functionality and checkout)

**Dockerize the project to run in isolated environments.**

**Trigger tests on every commit using GitHub Actions or Jenkins.**

**Implements screenshot on failures**

**Generate report**
